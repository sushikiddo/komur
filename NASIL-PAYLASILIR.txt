KÖMÜR'Ü BAŞKA BİLGİSAYARA KURMA

1. Komur-Setup-1.1.0-x64.exe dosyasını ve yanındaki .sha256 dosyasını paylaşın.
2. Alıcı Windows 10/11 64 bit bilgisayarında kurulum dosyasını açsın. Python kurması gerekmez.
3. Kurulum sonunda açılan yardımcıdan isteğe bağlı ücretsiz yerel AI ve ses modellerini kursun.
   Model indirmeleri birkaç GB tutabilir. İlk indirme için internet gerekir; sohbet modeli sonra yerel çalışır.
4. Daha az RAM için hafif model önerilir. Türkçe sesli yanıt için Windows'un Türkçe konuşma sesi de gerekir.
5. Kediye çift tıklayın: küçük sohbet açılır. Geçmiş düğmesi büyük geçmiş/ayarlar penceresini açar.

Paket sizin konuşmalarınızı, notlarınızı, ayarlarınızı ve API anahtarlarınızı içermez.
Kurulum kod imzalı değildir; Windows yayımlayıcı uyarısı gösterebilir. Yalnız güvendiğiniz kaynaktan alın.
SHA-256 kontrolü: PowerShell'de Get-FileHash .\Komur-Setup-1.1.0-x64.exe -Algorithm SHA256

Dosya paylaşılmaya hazırdır; otomatik olarak bir web sitesine veya herkese açık hesaba yüklenmemiştir.
